# Morphogenesis Engine starten

Node.js 22.12+ oder 24+ mit npm, ein Browser mit WebGL 2 und Modul-Worker-Unterstützung. Installation: `npm ci`, Start: `npm run dev`. Die ausgegebene lokale Adresse öffnen. `npm run check`, `npm test`, `npm run build` prüfen Typen, numerische und asynchrone Verträge sowie den statischen Produktionsbuild. `npm run preview` zeigt den gebauten Stand. Für Hosting den gesamten Inhalt von `dist/` einschließlich Worker-Assets ausliefern. Unterverzeichnisse benötigen einen passenden Vite-Basispfad.

## Level 2 bedienen
Die zwölf Timeline-Zustände integrieren 480 + n×96 Schritte desselben seed-initialisierten Gray–Scott-Systems. Die Konzentration steuert die dreidimensionale Dichte, aus der Marching Tetrahedra eine neue Oberfläche berechnet. Mit der Timeline einen Zeitpunkt wählen: Dies pausiert die Wiedergabe und berechnet den gewählten Zustand. Wiedergabe führt die Chemie schrittweise weiter, wartet auf fertige Netze und endet beim letzten Zustand. Jeder Zustand kann eine andere Vernetzung haben; deshalb gibt es keinen künstlichen Vertex-Morph zwischen den Netzen und keinen behaupteten nahtlosen Loop. Die zusätzliche GPU-Deformation verformt den jeweils sichtbaren Zustand räumlich.

Mausziehen oder Pfeiltasten bei fokussierter Szene drehen die Kamera, Mausrad oder +/− zoomen. „Ansicht“ setzt die Kamera zurück. „Geschwindigkeit“ steuert die Wiedergabe und „Deformation“ die ergänzende räumliche Bewegung. „Detailgrad“ berechnet denselben chemischen Zeitpunkt in anderer Auflösung. „Neue Welt erzeugen“ verwendet einen neuen Seed am Beginn der Timeline. Reduced Motion startet pausiert.

Die komplette CPU-Generierung läuft in einem Modul-Worker. Währenddessen bleibt der bisherige Zustand sichtbar und die Oberfläche bedienbar. Fortschritt zeigt erreichte Verfahrensstufen, keine geschätzte Restzeit. Ein neuer Auftrag beendet veraltete Berechnungen. Wiederholte Zustände können aus einem begrenzten CPU-Cache geladen werden. Die Berechnung selbst kann auf langsamen Geräten weiterhin mehrere Sekunden dauern; Worker-Auslagerung beschleunigt sie nicht automatisch.

„Zustand speichern“ lädt den aktuell sichtbaren Geometriezustand als `.mge` herunter. „Zustand laden“ prüft eine solche Datei und zeigt den gespeicherten Zustand. Der Bake enthält quantisierte Geometrie und chemische Metadaten, keine ausführbaren Skripte. Import pausiert die Wiedergabe. Fehler behalten die bisherige Szene. Format und Grenzen: [ASSET_FORMAT.md](ASSET_FORMAT.md).

## Architektur und Umfang
`src/morphology.ts`: numerisches chemisches Ausgangs-/Zeitfeld und implizites Volumen. `src/isosurface.ts`: generische Extraktion. `src/bake.ts`: CPU-Pipeline für Geometrie, Normalen und Materialfarben. `src/morphogenesis.worker.ts`: Worker-Einstieg mit Buffer-Transfer. `src/generation.ts`: Auftragsverwaltung, Abbruch und Cache. `src/asset-format.ts`: validiertes Bake-Format. `src/world.ts`: Darstellung eines fertigen Zustands. `src/viewer.ts`: Zeitsteuerung, Kamera, GPU-Ressourcen und asynchrone Integration. `src/ui.ts`/`src/style.css`: Oberfläche; `src/main.ts`: Verdrahtung. Die SPA benötigt weder Backend noch Konten oder externe Laufzeitressourcen.

Die Chemie ist zweidimensional und steuert ein dreidimensionales Dichtefeld. Dies ist keine validierte biologische oder Fluid-Simulation. Die Struktur enthält keine vorgefertigten Motivkörper. Einzelne Remeshing-Zustände werden diskret ausgetauscht; kontinuierliche Topologieinterpolation, VAT-Sequenzen, WebGPU und Streaming sind spätere Erweiterungen. Desktop ist der aktuelle Prüfbereich; Mobile ist ausdrücklich vertagt. Referenzhardware-Profiling und eine öffentliche Bereitstellung sind nicht Bestandteil der lokalen Abnahme. Plan: [PLAN.md](../PLAN.md), aktueller Nachweis: [VERIFICATION.md](VERIFICATION.md).
